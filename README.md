# 🐍 Python Fundamentals — Conteúdos Estudados

Formação **Python Fundamentals** concluída pela [DIO](https://www.dio.me/), com foco nos fundamentos da linguagem Python, programação estruturada, Programação Orientada a Objetos e manipulação de arquivos e dados.

## 📚 Conteúdos estudados

### Módulo 1 — Fundamentos do Python

- Variáveis
- Constantes
- Tipos de dados
- Operadores
- Indentação e blocos de código
- Estruturas condicionais
- Estruturas condicionais aninhadas
- Estruturas condicionais ternárias
- Estruturas de repetição
  - `for`
  - `while`
- Controle de fluxo
  - `break`
- Strings

### Módulo 2 — Estruturas de Dados e Funções

- Listas
- Tuplas
- Conjuntos (`set`)
- Dicionários
- Funções
- Parâmetros e argumentos
- Organização e reutilização de código

### Módulo 3 — Programação Orientada a Objetos (POO)

- Classes e instâncias
- Construtores e destrutores
- Herança
- Encapsulamento
- Polimorfismo
- Conceitos fundamentais de Programação Orientada a Objetos

### Módulo 4 — Recursos Avançados e Manipulação de Dados

- Decoradores
- Iteradores
- Geradores
- Data e hora
- Fusos horários
- Manipulação de arquivos e diretórios
- Biblioteca `os`
- Biblioteca `shutil`
- Biblioteca `pathlib`
- Manipulação de arquivos CSV
- Leitura e escrita de arquivos
- Criação e manipulação de diretórios

## 🎯 Objetivo da formação

A formação proporcionou uma base sólida em Python, passando desde os fundamentos da linguagem até conceitos de Programação Orientada a Objetos e manipulação de arquivos e dados.
